## Study Priority Order
1. **Go basics** — understand syntax, patterns, and how to contribute to backend services; be ready to read/modify Go code
2. **Observability tooling** — Honeycomb (tracing, queries), Datadog (dashboards, APM); know how to debug distributed failures
3. **CI/CD & CircleCI platform** — understand pipelines, workflows, orbs, executors; know the product you'll be building on
4. **React advanced patterns** — performance (memoization, lazy loading, virtualization), design systems, compound components
5. **System design for developer tools** — pipeline UIs, real-time build status, large-scale job orchestration
6. **Behavioral** — STAR stories tailored to CircleCI values: incremental delivery, observability, cross-functional partnership
